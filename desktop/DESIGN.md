# 桌面設計系統

WPF 桌面採用 .NET 10 官方 Fluent Theme。應用程式資源位於 `wpf/DesignResources.xaml`，色彩及主題生命週期由 `wpf/DesignSystem.cs` 管理；沒有第三方 UI 套件。標準來源為 [WPF Fluent Theme](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/whats-new/net100)、[Fluent 2 Layout](https://fluent2.microsoft.design/layout)、[Fluent 2 Typography](https://fluent2.microsoft.design/typography) 與 [Fluent 2 Accessibility](https://fluent2.microsoft.design/accessibility)。

## 共用資源

| 項目 | 現行規則 |
| --- | --- |
| 色彩 | `Canvas` 背景、`Surface` 卡片、`TextPrimary`／`TextSecondary` 文字、`Stroke` 控制項邊界、`Divider` 結構分隔、`Hover`／`SelectedSurface`／`SelectedText` 互動、`Accent` 選取指示、`Warning` 擷取註記。一般卡片使用底色與間距分組；高對比使用系統色邊框與直角。 |
| 字型 | Segoe UI Variable、Segoe UI、Microsoft JhengHei UI 依序 fallback；內文 14、輔助文字 12、區塊標題 16、頁標題 28。JSON 使用 Consolas 14。 |
| 間距 | 以 4 DIP 為基準；控制項間 8、區塊間 16、卡片內距 20、頁面上方 24、一般水平內距 28／緊湊水平內距 16。頁標題下方 20，第一個欄位不另加重複上間距。 |
| 形狀 | 設定卡片圓角 8、導覽項目圓角 6。標準輸入、按鈕、核取、選項、下拉選單保留官方 Fluent 模板及狀態。 |
| 圖示 | 導覽使用系統 Segoe Fluent Icons，fallback 為 Segoe MDL2 Assets；應用程式圖示保留現有兩種資產。圖示不替代可存取名稱。 |
| 狀態 | 選取同時使用底色與指示條；鍵盤焦點顯示外框。停用、滑鼠懸停及按下狀態由原生模板管理。連線狀態、監控錯誤、未知／缺失值與擷取限制保留文字，不只依賴顏色。 |

## 主題與可存取性

預設跟隨 Windows。外觀頁可切換淺色／深色，立即同步主視窗、獨立監控與診斷視窗。選擇只在本次程序期間生效，不寫入 Python 設定，也不更改 Windows 主題。Windows 使用者偏好與高對比事件會重新套用資源。

高對比優先於色彩選擇，使用 Windows `SystemColors`，並改用原生非 Fluent 控制項主題；不修改系統高對比設定。`ThemeMode` 的 `WPF0001` 僅在 `DesignSystem` 指定 API 呼叫區段局部停用，專案持續將其他警告視為錯誤。

標籤與輸入欄位以 `Label.Target` 關聯，搜尋、篩選、JSON 閱讀器、圖示選項及紀錄切換按鈕 有明確 Automation 名稱。Tab／Shift+Tab 使用原生焦點順序；方向鍵切換導覽項目，Ctrl+Tab 切換頁面，Alt+1～5 直接切頁，Ctrl+S 儲存。JSON 尋找保留 Ctrl+F、F3／Shift+F3 與 Escape。

## 布局

五個頁面共用左側導覽。四個設定頁的儲存操作位於固定頁標題旁，內容捲動時持續可用；連線已啟動時另顯示儲存並重連。請求監控不顯示設定操作，Ctrl+S 仍可儲存草稿。底部固定顯示文字連線狀態、原有完整診斷文字及依狀態切換的啟動／停止按鈕，更多選單保留獨立監控、系統匣及退出操作。診斷文字過長時截短顯示，完整文字保留於 tooltip 與可存取文字；「連線已啟動」描述程序狀態，遠端可用性仍依既有診斷確認。寬度小於 920 DIP 時，導覽縮為圖示列、水平內距縮為 16、頁標題改為 24 DIP，仍保留 tooltip、名稱及鍵盤操作。

設定內容可垂直捲動，數值欄位採等寬兩欄。副檔名、完整檔名及額外排除名稱以可換行的獨立項目框顯示，不顯示分隔符；點選項目可編輯或移除，也可使用右鍵選單或 Delete 移除，新增按鈕可加入項目；各清單以分隔線區隔。項目不變時保留原有設定文字；修改僅替換、刪除或附加對應項目，仍由原後端驗證，不自動修復無效路徑或萬用字元。圖示選項依寬度換行，以圖片與原生 radio 顯示選取狀態，名稱保留於可存取資訊及提示；儲存後沿用原有圖示套用流程。

請求監控與獨立監控共用 `MonitorView`／`JsonPane`。搜尋與動作位於第一列，工具／狀態篩選與跟隨最新位於第二列。紀錄列高 40 DIP，儲存格文字垂直置中，整個儲存格含空白內距均可點選，手動點選或方向鍵導覽立即停止跟隨最新；表格保留虛擬化。時間顯示至秒，使用 Segoe UI 等寬數字排列與冒號兩側細空白，最小欄寬 112 DIP、左右內距各 12 DIP；間距介於原緊湊顯示與整段 Consolas 空白顯示之間，原始時間與匯出格式不變。執行結果的錯誤與傳輸錯誤使用錯誤色，未知或不完整結果不推斷成功。「資料擷取」無已知限制時顯示「—」，部分內容使用警示色，缺少內容明確顯示「內容缺失」；「—」不代表已獨立確認完整。詳情資訊列保留當筆欄位，截短內容可透過 tooltip 或請求 JSON 閱讀。請求／回應分頁保留選取與焦點樣式；獨立監控不顯示再次分離命令。

請求監控預設顯示完整寬度列表，保留全部六欄，欄位超出寬度時可水平捲動。頁面右上角的圖示按鈕開啟整頁 JSON；再次點選返回完整列表。主視窗與獨立監控使用相同頁首、列表與詳情元件。雙擊紀錄或 Enter 亦可開啟，Alt+Left 返回列表並恢復選取與鍵盤焦點。開啟詳情會停止跟隨最新，搜尋與篩選列暫時隱藏但保留條件。

JSON 詳情佔滿內容區域，頂部沿用列表表頭樣式，依相同欄位順序顯示時間、工具、參數摘要、執行結果、耗時、資料擷取，下方呈現一筆紀錄，文字沿用列表大小與色彩，不附加「執行／擷取」前綴或空選取提示。資訊列寬度不足時可水平捲動，完整欄位保留於 tooltip 與 JSON。右側「<」「>」依目前篩選與排序後的列表順序切換上一筆／下一筆，顯示當前位置與總筆數；首尾、空列表與無選取時停用不適用方向，不循環跳轉。切換紀錄會同步更新頂部資訊與 JSON，回到列表保留目前紀錄；尺寸切換不改變列表／詳情模式。

JSON 預設上色，另可切換欄位檢視；控制列與閱讀內容使用一致內距，擷取註記預設收合、可展開閱讀，內容捲動高度依空間限制於 32～72 DIP，完整文字及原有紀錄複製／匯出保留。缺少內容時直接展開狀態與註記。JSON 不換行時按目前有界頁最長文字行計算頁寬，水平捲動範圍隨內容改變；自動換行時使用可用閱讀寬度。唯讀文字閱讀器的內部捲動區撐滿可用高度，水平捲動條位於閱讀區底部；不顯示插入游標或輸入框焦點底線，文字選取／複製與搜尋相符項目反白保留。視窗尺寸改變不重新格式化或載入 payload。

設定頁保留授權、DPAPI、固定安全排除及控制模式風險文字；監控保留敏感內容提示與擷取限制。所有儲存、啟停、模式確認、監控資料與匯出都沿用原有後端及格式。

## 驗證邊界

`DesignChecks` 只由具 fixture 防護的整合測試呼叫，覆蓋深淺色、未儲存草稿／閱讀狀態、緊湊布局、焦點及 Windows 色彩資源分支，並輸出實際 WPF 控制項渲染 PNG。色彩資源分支的模擬不能取代真正開啟 Windows 高對比後的測試；渲染 PNG 也不能取代螢幕閱讀器、跨 DPI、IME 或人工流暢度驗收。
