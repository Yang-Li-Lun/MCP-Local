# 自啟動與工程優化

## 啟用

重新開啟設定介面，在「連線設定」勾選「Windows 登入後自動啟動並連線」，確認已保存 API 金鑰，再按「儲存設定」。預設不會替既有安裝啟用此選項。

工作名稱為 `MCP-Local Auto Connect <目前使用者 SID>`，只在該使用者登入後以 `pythonw.exe -B autostart.py` 執行，使用最低權限及 InteractiveToken。排程不包含金鑰；背景程序透過現有 DPAPI 金鑰檔載入。排程器忽略重複執行，異常結束每分鐘最多重試三次。

「檢查背景狀態」區分工作遺失、設定不一致、背景程序與通道程序是否存在；程序存在不代表遠端請求成功。「停止背景連線」只停止本程式目前使用者的排程工作。「套用並重連背景」保存設定後停止並重新啟動該工作。重新儲存已勾選的設定可修復排程。取消勾選並儲存會移除登入工作；需要立即停止時另按停止背景連線。

GUI／CLI 手動連線保留原操作方式；背景程序會自動重連。暫時失敗以 5、15、30、60、300 秒退避並加上 ±10% 隨機延遲；持續運作一分鐘才重置。設定、遷移、DPAPI、完整性、認證及重複程序錯誤不會無限重試。供應商錯誤分類只能使用有限的退出階段及已知認證指標，未知授權錯誤可能仍落入一般啟動失敗。

## 保存與安全

- 已授權 v1/v2 設定載入時遷移至 v3；未確認的舊設定仍需原有遷移確認。
- 不接受重複或互相包含的 Root。已有重疊設定會被拒絕，不自動擴大或重選範圍。
- 相同設定不重寫；設定備份最多五份，profile 備份最多三份。輪替只處理固定檔名加 32 位十六進位 UUID 的 `.bak`，連結備份保留並回報錯誤。
- 背景日誌位於 `%LOCALAPPDATA%\MCP-Local\background.log`，只保存時間與事件分類，每份 1 MiB，最多三份含目前檔案。
- `vendor-integrity.json` 的 SHA-256 與既有 v0.0.14 SPDX 一致。每次啟動檢查成品，不自動接受新雜湊。更新供應商時須一起核對官方成品、SHA256SUMS、provenance（若提供）、SPDX 與授權，再更新清單及測試。不可單獨抽換內嵌 cloudflared。

## 分頁與搜尋

列舉第一頁建立純記憶體名稱快照，後续分頁不重掃。閒置 60 秒、最長五分鐘；每個讀取器八份、全程序 32 份、每份十萬筆、合計 25 萬筆，採 LRU 淘汰。過期項目在下次快取操作時回收；容量始終有上限。每份快照只保存名稱與掃描統計，不保存檔案內容。讀取及搜尋仍獨立驗證路徑。

搜尋採 64 KiB 二進位區塊、增量 UTF-8 解碼；即使命中也會驗證該檔剩餘內容，尾端 UTF-8 錯誤或 NUL 會丟棄整檔候選。超長行只保留 600 字片段及查詢尾端。實際讀取位元組含探測資料，受單檔與總量上限限制。

## 驗證指令

```powershell
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -B benchmark.py --entries 10000
.\.venv\Scripts\python.exe -B benchmark.py --entries 1000 --soak-seconds 28800
```

benchmark 支援 1,000／10,000／50,000／100,000 筆，僅使用自動清理的暫存固定資料。`python_peak_bytes` 是 tracemalloc 觀察的 Python 配置峰值，不是 RSS。週期模式是資料讀取負載檢查，不代替真實網路斷線、登出、睡眠及長時間程序 handle 驗收。

一般 HTTPS MCP 可用 `remote_smoke_test.py --url <HTTPS端點> --fixture-root-id <測試代號>`；測試 Root 僅放 `shared/README.md` 副本。認證只從 `MCP_SMOKE_BEARER` 環境讀取。停止後可加 `--expect-unavailable`，重啟再執行一般驗收；認證錯誤不算通道停止成功。工具不停止現有通道。

目前安裝使用 OpenAI Secure MCP Tunnel，需透過支援的 ChatGPT／Codex 連線或 Responses API 的 `tunnel_id` 呼叫；不能把控制平面 URL 當成一般 MCP URL。參考 [OpenAI 官方通道文件](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)。

`secure_tunnel_smoke.py --model <已授權模型>` 適用目前的 `main` Root，只核准 `MCP-Local/shared/README.md` 前十行的精確參數。它會將這份測試文件傳至 OpenAI 並產生 API 用量，應在明確授權後執行。金鑰從 DPAPI 讀入，沒有命令列金鑰參數。成功只代表這份固定文件的真實遠端讀取成功，不代表其餘工具或停止／恢復驗收通過。

Windows 登入／登出、斷網復原與 8–24 小時實際運作須另外驗收。Handle-based TOCTOU 防護、read_file 全面串流與完整 IPC 按設計暫緩。
