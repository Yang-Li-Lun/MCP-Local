# MCP-Local 多資料夾功能驗證報告

日期：2026-09-13。範圍：原工程設計第一至第三階段及本機驗收。Git review 為選配，本次未納入；未新增第三方相依套件或替換供應商二進位檔。

## 完成內容

- 最多八個具名 root、明確 default_root、每 root 額外排除、共用驗證與 GUI 管理。舊四工具保留預設 root 相容呼叫，新增 root_id；游標限於各自 root。
- workspace_info、list_projects、project_context、read_files，共八個唯讀 MCP 工具，annotations 全部符合唯讀契約。
- 第一層專案探索最多 100 筆；固定入口摘錄每檔最多 80 行、24,000 字元，總 JSON 64 KiB，不追蹤內容中的路徑。
- 批次最多十檔、先驗證全部路徑、沿用 FileReader 讀取、回報行數及略過原因，文字 JSON 最多 512 KiB。已透過真實 STDIO 驗證中文輸出的序列化容量。
- 搜尋選用 0–3 行前後文，每行最多 600 字元，命中 JSON 累計最多 100,000 字元，沿用實際掃描 bytes 與截斷欄位。
- v1 已確認設定經驗證後備份並原子遷移為 v2，僅保留原 root 為 main；v0 仍需首次確認。GUI 與 PowerShell/CLI 共用設定與快照流程。一般設定備份排除金鑰，DPAPI 不參與遷移。
- 全域固定安全與產物排除不可取消；全域自訂排除與 root 額外排除的聯集最多 128 項，保存前驗證。固定排除另外強制生效。
- README 與介面使用說明已更新，包含設定備份還原、批次欄位、快照、重新連線及用戶端工具清單更新流程。

## 驗證邊界與使用

未啟動真實遠端通道，未讀取或修改使用者實際設定、DPAPI 金鑰及分享範圍；遷移與 GUI 保存使用非敏感暫存 fixture。未將本機 STDIO 成功視為遠端成功。

使用新版時，關閉舊介面後重新開啟，在「共享資料夾」頁加入／更新明確授權的範圍並設定預設 root，按儲存及「套用並重新連線」。用戶端需重新整理工具清單，確認八個工具與新 schema。遠端仍需另行驗證允許檔案讀取、拒絕路徑、停止失效和重啟恢復。
