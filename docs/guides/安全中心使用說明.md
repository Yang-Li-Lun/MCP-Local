# 安全中心使用說明

開啟 WPF 左側第六頁「安全中心」（Alt+6）。此頁的「儲存設定」只保存安全設定，不會改變正式共享資料夾、通道、金鑰、排程或三種權限模式。

1. 安全中心預設開啟「總覽」，區分已儲存政策、已生效、等待執行層確認及異常，並顯示回傳防護、主機授權及最近事件。等待確認或異常不代表防護已生效；可從「查看診斷」直接進入診斷與恢復。
2. 在「設定」調整防護選項，按「儲存設定」並在本機確認。回傳防護依賴敏感資訊偵測，須先關閉回傳防護才能停用偵測；介面不會自動改寫開關。未修改或相依設定無效時不可儲存。儲存會撤銷現有授權，仍須等待執行層確認。首次升級預設關閉，修改只形成草稿。
3. 在「總覽」選擇 5、10、15 分鐘或「自訂時間」，再按單一「本機授權」並確認。選擇時間本身不會授權；自訂時間為 1–60 分鐘且不得超過已儲存上限，未儲存草稿不影響此上限。只有已儲存政策啟用主機限時授權、主機連線與授權世代均獲執行層確認時才能送出，無法使用時會顯示原因。
4. 授權有效時顯示剩餘分秒及「立即撤銷」，變更時間需先撤銷。撤銷仍要求本機確認；既有主機工作依已儲存策略終止或保留至原期限，不再接受新的命令及互動輸入。通訊失效時一律要求終止主機工作，停止未確認會明示。
5. 「設定 → 進階設定」提供授權上限、工作處置、自訂規則、合成測試與草稿重設。「設定 → 診斷與恢復」保留原始通訊及工作資料，異常或未確認時提供「安全恢復」；恢復仍須本機確認，不會自動延長或授權。
6. 「安全事件」依類型與風險自動篩選，不需另按套用；「更新事件」可取得最新紀錄。事件名稱與詳情使用繁體中文，同頁的「原始診斷資訊」保留識別碼與完整鏈資料。「匯出全部事件」保存完整 JSON 事件鏈，不受目前篩選限制。展開「清除事件」，檢視最新事件並匯出需要保留的紀錄後，輸入「清除安全事件」，按「確認清除全部事件」並本機確認；清除仍核對最新事件版本並保留清除紀錄。

切換分區與自動更新狀態會保留未儲存草稿。「還原預設草稿」只改草稿，另按儲存才會停用政策；「捨棄草稿」載入已儲存設定。兩者覆蓋未儲存變更前會要求確認，從桌面選單退出亦會確認未儲存的安全設定。草稿不影響執行中的 MCP。操作進行中會防止重複提交；逾時會提示結果未確認，等待原回覆或查詢實際狀態，不要把逾時當作已撤銷或失敗後重送。

啟用回傳防護後，MCP 文字與結構化回傳會遮罩或阻擋。圖片、音訊、binary、超限與無法完整檢查的資料會拒絕；Session 的執行中輸出暫存至結束後完整檢查，溢位 buffer 不放行。需要查看原始程式進度時應在本機自行檢視，或由本機操作者評估是否調整政策。

安全事件不保存敏感原文；原始請求監控是另一個有界記憶體功能，可能包含敏感輸入。匯出原始監控前應自行檢視。此安全中心不是同 Windows 帳戶的憑證沙箱，也不是完整網路防外洩工具。

若政策或稽核檔案損毀／遺失，系統保留檔案並拒絕靜默降級。請由本機操作者還原有效原檔後按恢復；不要刪檔來嘗試關閉保護。稽核容量已滿時先匯出有效事件，再受控清除並恢復。完整架構及限制見[安全中心架構](../architecture/安全中心.md)。
