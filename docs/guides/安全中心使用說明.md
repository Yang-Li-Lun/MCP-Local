# 安全中心使用說明

開啟 WPF 左側第六頁「安全中心」（Alt+6）。此頁的「儲存設定」只保存安全設定，不會改變正式共享資料夾、通道、金鑰、排程或三種權限模式。

1. 安全中心預設開啟「總覽」，集中顯示已儲存政策、執行層確認、回傳防護、主機授權及最近安全事件。未確認或異常不代表防護已生效。
2. 在「設定」調整常用開關及回傳處理策略，按「儲存設定」並在本機確認。儲存會撤銷現有授權；須等待執行層確認，尚無受管理用戶端時不能視為已驗證遠端生效。首次升級預設關閉，修改只形成草稿。
3. 在「總覽」選擇 5、10 或 15 分鐘並本機確認。超過已儲存上限的選項停用；上限未滿 5 分鐘時，可在「設定 → 進階設定」輸入其他時間。未儲存的上限不影響授權。確認後仍須查看執行層確認，不能只憑送出成功判斷生效。
4. 「立即撤銷」要求本機確認；Session 依已儲存策略終止或保留至原期限，不再接受新的命令及互動輸入。通訊失效時一律要求終止主機 Session，停止未確認會明示。
5. 「設定 → 進階設定」提供授權上限、其他授權時間、Session 處置、自訂規則、合成測試及診斷。診斷顯示通訊、Session 與事件原始資料；「安全恢復」重新驗證，不會自動延長或授權。
6. 「安全事件」自動載入最近紀錄，可依類型與風險篩選、分頁及選取詳情。「匯出事件」保存完整 JSON 事件鏈。清除前先檢視最新事件並匯出需要保留的紀錄，輸入「清除安全事件」，按「清除事件」並本機確認。

「還原預設」只改草稿，另按儲存才會停用政策；「重新載入」捨棄草稿。草稿不影響執行中的 MCP。操作逾時會提示結果未確認，等待原回覆或查詢實際狀態，不要把逾時當作已撤銷或失敗後重送。

啟用回傳防護後，MCP 文字與結構化回傳會遮罩或阻擋。圖片、音訊、binary、超限與無法完整檢查的資料會拒絕；Session 的執行中輸出暫存至結束後完整檢查，溢位 buffer 不放行。需要查看原始程式進度時應在本機自行檢視，或由本機操作者評估是否調整政策。

安全事件不保存敏感原文；原始請求監控是另一個有界記憶體功能，可能包含敏感輸入。匯出原始監控前應自行檢視。此安全中心不是同 Windows 帳戶的憑證沙箱，也不是完整網路防外洩工具。

若政策或稽核檔案損毀／遺失，系統保留檔案並拒絕靜默降級。請由本機操作者還原有效原檔後按恢復；不要刪檔來嘗試關閉保護。稽核容量已滿時先匯出有效事件，再受控清除並恢復。完整架構及限制見[安全中心架構](../architecture/安全中心.md)。
