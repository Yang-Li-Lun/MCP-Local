# 安全中心使用說明

開啟 WPF 左側第六頁「安全中心」（Alt+6）。此頁的「儲存安全政策」只保存安全設定，不會改變正式共享資料夾、通道、金鑰、排程或三種權限模式。

1. 在「安全政策」查看已儲存啟停狀態與實際執行層確認。舊安裝首次開啟預設關閉；勾選或修改規則只產生草稿。
2. 設定主機授權上限、到期處置、敏感規則及回傳策略。可先按「合成偵測測試」及「預覽處理結果」，測試只使用內建合成樣本。
3. 按「儲存安全政策」並在本機確認。原限時授權會撤銷；等待頁首顯示執行層已確認。未連線時顯示尚無受管理用戶端，不能當成已驗證遠端生效。
4. 使用主機模式且啟用授權保護時，輸入本次分鐘數並按「本機授權」。確認後查看剩餘時間及執行層確認；到期後不能啟動新命令或送入新 stdin。
5. 「立即撤銷」使新命令與互動輸入失效；Session 依已保存策略終止或保留至原期限。通訊失效時一律要求終止主機 Session，停止未確認會明示，不能當作已停止。
6. 「本機授權通訊」可查看連線診斷與每個用戶端的政策版本、Session 及攔截計數。「安全恢復」重新驗證，不會自動延長或授權。
7. 「安全事件」可依類型與風險查詢，每頁 100 筆；選取一筆查看詳情。「匯出已驗證事件」保存完整 JSON 事件鏈。清除前先查詢最新事件，輸入「清除安全事件」，再按「受控清除」並本機確認。

「還原預設草稿」只改草稿，另按儲存才會停用政策；「重新載入已儲存設定」捨棄草稿。草稿不影響執行中的 MCP。操作逾時會提示結果未確認，等待原回覆或查詢實際狀態，不要把逾時當作已撤銷或失敗後重送。

啟用回傳防護後，MCP 文字與結構化回傳會遮罩或阻擋。圖片、音訊、binary、超限與無法完整檢查的資料會拒絕；Session 的執行中輸出暫存至結束後完整檢查，溢位 buffer 不放行。需要查看原始程式進度時應在本機自行檢視，或由本機操作者評估是否調整政策。

安全事件不保存敏感原文；原始請求監控是另一個有界記憶體功能，可能包含敏感輸入。匯出原始監控前應自行檢視。此安全中心不是同 Windows 帳戶的憑證沙箱，也不是完整網路防外洩工具。

若政策或稽核檔案損毀／遺失，系統保留檔案並拒絕靜默降級。請由本機操作者還原有效原檔後按恢復；不要刪檔來嘗試關閉保護。稽核容量已滿時先匯出有效事件，再受控清除並恢復。完整架構及限制見[安全中心架構](../architecture/安全中心.md)。
