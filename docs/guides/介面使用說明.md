# MCP-Local 快捷設定

> [文件索引](../INDEX.md)；本文命令與未另行註明的檔案路徑皆以專案根目錄為基準。

雙擊「開啟連線設定.vbs」即可開啟繁體中文介面，不會留下命令列視窗，桌面需已安裝 .NET 9 Windows Desktop Runtime；來源建置與隔離入口見 [WPF 桌面](../../desktop/README.md)。

1. 按「加入資料夾…」選取允許讀取的專用資料夾，最多八個。
2. 確認通道識別碼，輸入執行階段 API 金鑰，按「啟動連線」。
3. 關閉或最小化視窗後，程式會留在右下角系統匣；圖示可能位於 Windows 的「顯示隱藏圖示」內。
4. 左鍵點圖示開啟設定；右鍵直接提供原生選單「開啟快捷設定、啟動連線、停止連線、退出程式」，不會彈出設定視窗或讓它出現在工作列。無法使用的動作會呈灰色。

## 權限模式

APP 的「權限模式」可明確切換並保存三種模式：唯讀（22 工具）、開發控制（34）與主機控制（36）；預設為唯讀。v1–v6 與所有舊 full_control 設定保守降為唯讀；v7 已授權的開發／主機模式保留，手動工具鏈欄位移除。
開發控制使用 Windows Sandbox VM 直接讀寫授權 root，安全工具鏈自動偵測並唯讀映射；GUI／CLI 不提供手動工具鏈設定。主機控制執行受信任的目前使用者主機命令，並提供受保護的跨 root 主機檔案 API。`full_control` 僅保留內部相容／回歸用途，不是公開模式。
切換並儲存會停止舊連線與 sessions 後重連，遠端無法提升或切換模式。開發 VM 關閉網路與剪貼簿且不繼承主機 profile／憑證；主機控制不是沙箱，可存取目前使用者可存取的檔案、設定與憑證。
完整限制、MIT 來源及驗收方式見 [權限模式說明](../architecture/完整控制模式.md)。

## 快捷調整

- 允許讀取的資料夾：加入、變更選取或移除選取；清單就是待儲存的授權範圍。
- 通道識別碼：直接修改文字欄位。
- 啟動顯示方式：勾選「下次開啟時直接縮到系統匣」，再儲存。
- 儲存設定：按鈕或 Ctrl+S。連線中的設定不會立即改變。
- 儲存並重連：先停止本次管理的舊連線，再使用新設定啟動；切換期間會短暫中斷。
- 停止：保留介面，停止其管理的通道及子程序。
- 結束程式：停止其管理的連線並退出，不會終止其他視窗啟動的通道。

## 進階讀取設定

切換至「進階讀取設定」分頁，所有變更與連線設定一起儲存。按「儲存並重連」才會套用到新的連線；單純儲存不會改變正在執行的讀取範圍。

| 設定 | 預設 | 可調範圍 |
| --- | --- | --- |
| 單檔讀取上限 | 2 MiB | 1 byte 至 64 MiB，可輸入小數 MiB |
| 掃描檔案上限 | 3,000 | 1 至 100,000 個 |
| 掃描項目上限 | 12,000 | 1 至 300,000 個，包含資料夾與被略過的項目 |
| 搜尋累計讀取上限 | 32 MiB | 1 byte 至 1,024 MiB，可輸入小數 MiB |

三份清單都可新增、刪除及清空，以逗號、分號或換行分隔，不區分大小寫：

- **允許副檔名**：例如 `.txt, .md, .custom`。新增副檔名仍只接受 UTF-8 純文字，並不增加 PDF 或圖片解析能力。
- **允許完整檔名**：例如 `README, Dockerfile`。副檔名或完整檔名符合任一項即可讀取；兩份清單都清空只停用文字 reader；一般檔案列舉、metadata 與專用格式工具仍遵守 root 與排除規則。
- **排除資料夾／檔名**：例如 `build, 私用資料, credentials.json`。比對各層的完整名稱，不是相對路徑，也不使用萬用字元。排除優先於允許；移除名稱只取消自訂部分，固定安全與產物排除仍然有效。

「還原進階預設值」只重設此分頁的未儲存內容，不清除資料夾、通道識別碼或 API 金鑰。還原後仍需儲存或套用。

「最大值」一次將單檔設為 64 MiB、掃描檔案設為 100,000 個、掃描項目設為 300,000 個、搜尋累計容量設為 1,024 MiB；不變更副檔名或排除清單。按下後仍需儲存或套用。

隱藏路徑（含 Windows Hidden 屬性）、符號／硬連結、重新解析點、跳出共享目錄與家目錄的限制固定保留；可選取磁碟根目錄，僅根目錄本身豁免 Hidden 屬性檢查。伺服器提供二十二個唯讀工具，list_files 支援 cursor 分頁，每頁最多 500 筆；分頁不會取消掃描上限。詳細欄位與目錄異動語意見 README。

新版本可自動載入舊設定並補上進階預設值。已開啟的舊版介面要在下次啟動程式時才會顯示新版功能。舊版僅存在記憶體的金鑰不會自動轉移；首次使用新版時輸入一次，後續便會自動帶入。

## 第一次切換至系統匣版

如果原本的 PowerShell 通道仍在執行，先回到原視窗按 Ctrl+C，再由新介面啟動。介面會攔截已有 tunnel-client 的情況，避免同時使用相同通道。

GUI 與 PowerShell 現在共用 settings.json 及 local-files-gui profile。首次遷移先載入舊 GUI 值，未確認前不允許啟動。選定資料夾、通道及進階設定，按「儲存設定」，對話框會提示舊 PowerShell 的 D:\codee 與此次選定值；確認後保存現行 settings_version=8。取消會保留原件，PowerShell 會提示回到介面完成遷移。

每次保存前在 settings.json 同目錄建立 settings.json.<隨機識別碼>.bak，備份包含一般設定、不含金鑰。設定損毀時拒絕覆寫。回復時先停止連線並退出介面，將選定備份複製回 settings.json，再開啟介面確認；api-key.dpapi 不需更換。備份不可移入共享目錄。

啟動及重連會重用既有 `profiles/local-files-gui.yaml`，不重寫、備份或輪替 profile；既有備份與 Credential 保留。只有 profile 不存在時才執行 `init`，不使用 `--force`。GUI、CLI 與登入啟動共用此流程，已驗證的授權根、識別碼、讀取設定及權限模式以 `doctor`／`run` 參數傳遞，無須改寫 profile。無效或連結 profile 會拒絕啟動，不自動重建。這些設定及備份目錄不能包含在 GUI 或 PowerShell 選定的分享範圍內。

設定存於 `%LOCALAPPDATA%\MCP-Local\settings.json`，通道設定存於其 `profiles` 子目錄，不放入預設共享目錄。API 金鑰按「儲存設定」後會透過目前 Windows 使用者的 DPAPI 加密，另存於 `%LOCALAPPDATA%\MCP-Local\api-key.dpapi`，不會寫入一般設定 JSON、日誌或命令列。下次使用相同 Windows 帳戶開啟程式會自動解密帶入；更新金鑰會替換密文，暫時清空輸入欄不刪除原先保存值。退出時會等待已提交的保存工作；尚未提交的輸入不會自動保存。可在連線設定勾選 Windows 登入後啟動到系統匣並自動連線。

啟動前呈現實際分享目錄。兩個入口共用連線鎖，且會攔截已存在的 tunnel-client；不自動停止其他連線。建立設定及檢查連線各有 60 秒逾時，常駐 run 不套用短逾時。停止或逾時會清理本次 Job 的子程序，GUI／CLI 手動連線可手動重啟；登入啟動的系統匣程式會依錯誤分類自動重試。

畫面顯示「通道程序執行中」表示程序仍存活；請在遠端重新整理工具清單，依實際模式確認 22／34／36 個工具並實際呼叫代表性工具確認可用性。失敗會顯示階段、結束代碼或逾時及建議操作。輸出由背景執行緒持續讀取，最多保留 8 KiB 尾端於記憶體，僅顯示分類摘要，不顯示或保存原始通道輸出。

原有 22 個唯讀工具的 UTF-8、路徑與讀取防護規則不變；控制工具是否註冊及其額外邊界由權限模式決定。文字 reader 副檔名、名稱排除、檔案大小與掃描上限由進階分頁設定。一般檔案探索與專用工具不使用文字白名單，詳見 [格式讀取說明](格式讀取說明.md)。可選取整個磁碟作為唯讀範圍；程式設定、備份與金鑰目錄仍自動排除，使用者家目錄不可直接設為根。

## 請求監控

由此 GUI 啟動 MCP 連線時，會自動啟用「請求監控」；連線結束、啟動失敗或使用者停止連線時停止收集。按「暫停監控」可暫停，按「恢復監控」收集後續呼叫；每次新連線都重新啟用，不延續上一條連線的暫停狀態。監控不會自行啟動、停止或重新連線。

選取紀錄後，下方「請求」與「回應」顯示 MCP 程序實際收到的 `tools/call` 與交付 STDIO 的對應回應，包括 JSON-RPC `id`、完整 `params`、`result` 或 `error`。JSON 值與結構保留，顯示排版不代表原封包空白或鍵順序。文字區內原本為字串的 JSON 仍保留為字串，不再轉成摘要。清單保留時間、工具、狀態及耗時；不同程序及並行請求分別追蹤，重複且無法判定的同時請求 ID 會明確標示，不猜測對應。

- 上方搜尋框以不分大小寫的字面文字比對工具名稱、已擷取的請求參數、路徑、回應及截斷說明。可組合工具與狀態篩選；從「更多 → 重設篩選」清除條件。點選「時間」「耗時」欄名切換排序，未知耗時維持在最後。
- 清單提供參數摘要。預設追蹤最新紀錄；手動選取歷史紀錄後暫停追蹤，後續新請求不會覆蓋選取。按「最新」恢復追蹤目前篩選條件下最新的紀錄。紀錄因容量限制淘汰或被篩選隱藏時，會清空閱讀區並顯示原因。
- 請求與回應分頁提供 JSON 與水平捲動；檢視種類另有「JSON（上色）」。從「檢視 → 尋找」開啟內容搜尋，「檢視」亦提供自動換行；Escape 關閉搜尋。搜尋涵蓋目前閱讀內容的所有分頁；Enter／F3 前往下一個、Shift+Enter／Shift+F3 前往上一個。文字區 Ctrl+F 聚焦搜尋、Ctrl+A 選取目前顯示頁。一般每頁最多顯示 4,096 字元，換行模式為 2,048 字元；不切斷 Unicode 代理對，尋找會切回 JSON 文字檢視並選取目前命中。
- 將內容左上角的「JSON」切換為「欄位」，可逐層展開 JSON 物件與陣列，每次載入 100 個子欄位；選取「載入後續欄位…」列可繼續載入。從「檢視 → 閱讀選取欄位」查看完整已擷取值；純量可直接雙擊。按「返回完整內容」返回；「檢視」亦提供摺疊全部欄位。大型字串仍使用分頁顯示。
- 拖曳清單與閱讀區之間的分隔線可調整空間。「更多 → 獨立視窗」承接目前篩選、排序與選取，之後各視窗可獨立閱讀；共用同一份監控資料，暫停與清除會影響兩邊。關閉獨立視窗不會停止連線。縮放視窗時，清單與閱讀區依目前尺寸配置，監控畫面仍持續更新；選取紀錄、閱讀位置與分隔線的大致比例會保留。
- 內容區的「複製」複製目前閱讀範圍的完整已擷取 JSON，不限目前顯示頁；在欄位範圍閱讀時僅複製該範圍，返回完整內容可複製整份請求或回應。「更多 → 複製完整紀錄」另含時間、狀態、耗時、截斷／省略說明及監控診斷。
- 「更多 → 匯出選取紀錄」只在你選定新檔名後寫入 UTF-8 JSON；包含選取紀錄與診斷，不匯出其他紀錄、不自動覆寫既有檔案。檔案與剪貼簿可能含原始敏感內容，請自行決定保存位置及後續處理。

底部狀態列顯示收集狀態與筆數；「診斷」可查看：目前紀錄中有截斷／省略的筆數、因歷史容量淘汰的筆數，以及可偵測的記憶體佇列覆寫所造成的事件遺失數。有截斷、淘汰、遺失或監控錯誤時，「診斷 !」會提示。事件數不等於請求數，淘汰／遺失計數為監控歷程累計，清除紀錄時歸零；不能據此保證沒有其他未偵測到的監控事件遺失。

**詳細內容可能包含金鑰、憑證、私人路徑與檔案內容。** 參數、搜尋文字、命令、工具回應中的 stdout／stderr、錯誤及任意文字均不再以白名單遮罩。監控只觀察現有請求與回應，不額外讀取金鑰、Credential、檔案或 Tunnel 設定，不新增遠端讀取紀錄的 MCP 工具。應用程式不自動將監控內容寫入檔案、日誌或設定，也不傳送至其他服務；只有使用者手動複製或匯出選取紀錄時，才寫入剪貼簿或指定的新檔案。

每個請求及回應最多擷取約 **1 MiB JSON 內容**，另有 10,000 節點及 32 層深度限制。圖片、音訊及嵌入資源的二進位欄位不展開，保留類型／MIME 等欄位，並註明編碼長度與估計解碼大小。容量不足時保留可容納的前段，截斷位置、原因與可得的原始／保留長度可由「診斷」查看，完整紀錄複製與匯出亦保留這些說明；清單標示「部分內容」。說明不覆蓋原始欄位。

歷史最多 **200 筆、32 MiB 序列化內容**，程序間環形記憶體約 **18 MiB**。每次 GUI 更新最多取四個事件，詳情顯示採有界分頁，使用「上一頁／下一頁」查看已擷取的完整內容；分頁不另行截斷紀錄。超限會淘汰舊紀錄或丟棄監控事件，不阻塞正常呼叫。「執行中」只表示尚未觀察到完成，佇列壅塞或斷線時不保證取得回應。

「更多 → 清除紀錄」清除清單、詳情與待處理事件，清除前尚未完成的回應不會稍後補回。暫停及斷線保留已取得的歷史，退出 GUI 時釋放；GUI 意外終止後 MCP 程序不再收集。記憶體通道使用每條連線獨立的隨機名稱，不是對相同 Windows 使用者之受信任主機命令的隔離邊界。

更新程式後，請自行在適當時機退出舊 GUI，再開啟更新後的 GUI 並啟動連線。由其他 CLI／GUI 啟動的既有連線不會接管；MCP 用戶端若仍連著舊程序，請手動重新連線後發出新的工具呼叫。工具契約不變。

## 本機驗證

在儲存庫根目錄執行：

```powershell
.\.venv\Scripts\python.exe -m py_compile local_files_gui.py mcp_local/tray_windows.py local_files_mcp.py
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
```

Windows 介面測試會短暫建立設定視窗與系統匣圖示；不會使用真實金鑰或連上遠端通道。

## 多資料夾管理

1. 在首頁按「加入資料夾…」選擇一個專用位置，最多八筆。
2. 要修改位置，選取一筆按「變更選取…」；要移除，選取一筆或多筆按「移除選取」。
3. 清單可以暫時清空，但至少加入一個有效資料夾才能儲存或啟動。
4. 按「儲存設定」保存草稿。已連線時使用「儲存並重連」套用新的範圍。

不需輸入資料夾識別碼或名稱。順序保持不變，第一筆為舊客戶端省略 root_id 的相容性預設根。舊有個別排除規則會保留，變更路徑也不會移除它們；全域排除仍可在進階分頁修改。重複、互相包含、隱藏、連結及家目錄仍拒絕；磁碟根可選取，設定/金鑰目錄禁止列舉與讀取。其他包含設定/金鑰目錄的範圍仍拒絕。若已有 D:\codee、D:\download，請先移除這些子範圍，再加入 D:\；移除清單不會刪除磁碟檔案。失效位置會標示「無法使用」，請變更或移除後儲存。

舊版已授權設定會依現行設定格式遷移；保留既有識別碼、名稱、順序、排除、通道、讀取限制與 DPAPI 金鑰。recent 相容欄位仍保留但不再用於 GUI。未知或損毀設定保留原件。

## 2026-09-13 行為更新（優先於上方歷史說明）

金鑰改為按「儲存設定」時加密保存，不再於輸入 700 毫秒後自動覆蓋。清空欄位保留舊密文；保存不代表遠端認證通過。儲存、根路徑驗證及排程控制由單一背景工作執行；完成前不接受重複儲存。退出等待已開始的保存完成，但不再啟動後续連線。共享路徑失效會進入修復模式，先修正全部失效根並儲存後才能啟動。

相符排程不重建，不相符同名工作禁止強制覆寫。停用登入啟動不等於停止目前程序；保存失敗會補償排程變更，補償失敗另行呈現。正式排程及遠端連線未列入本次驗收。完整限制及復原方式請參見 [完整繁體中文說明](../../README_繁體中文.md) 與工程修正交付報告。

## 系統匣自啟動

「權限模式」頁提供三種選項：唯讀模式（22 工具）、開發控制模式（隔離 VM；34）、主機控制模式（受信任命令；36）。
主機模式使用受信任命令模型，可跨 root，命令也可存取使用者設定與憑證；檔案 API 防護及環境變數清理不等於命令沙箱。
切換必須本機儲存並確認，再停止舊連線／sessions 後重連。開發模式自動偵測安全安裝工具鏈並唯讀映射，不需手動清單。缺少 Windows Sandbox CLI 時拒絕命令；沒有額外工具鏈仍可使用內建 PowerShell，沒有主機 fallback。VM 關閉網路與剪貼簿，不繼承主機 profile／憑證。
詳細模式、CLI、契約及目前限制見 [權限模式說明](../architecture/完整控制模式.md)。

勾選「Windows 登入後啟動到系統匣並自動連線」並儲存後，下次登入會啟動同一個主程式，只顯示系統匣圖示並使用已保存的設定與金鑰連線。既有登入排程沿用 `autostart.py`，不建立第二份工作。重複登入啟動會安靜退出，不重複建立圖示或連線。

左鍵圖示開啟設定；關閉或最小化設定視窗會收回系統匣。右鍵可啟動、停止連線或退出程式。取消自啟動並儲存只影響下次登入，目前的系統匣程式與連線繼續執行。

介面統一使用「啟動連線」「儲存並重連」「停止連線」。儲存或啟停過程中，相關按鈕會暫時停用。登入啟動遇到暫時網路錯誤會延遲重試；按「停止連線」可取消重試。永久錯誤會提示使用者修正，不會無限重試。


## 目前工具版本（契約 13；含 2026-09-17 性能工具）

服務版本 `2026.10.06.1`，共 22 個唯讀工具；設定版本為 8。

- 已知專案先用 `project_context`；定位檔名用 `find_files`。它以相對路徑做不分大小寫字面包含比對，最多 10 詞、每詞 50 筆、合計 200 筆與 100 KiB；達上限即停，不保證完整清冊。
- 多個已知檔案直接使用 `read_files`，不必先掃描定位；每次最多 32 檔、總回傳仍為 512 KiB。多個名稱合併於一次 `find_files`，多詞合併於一次 `search_texts`；需要少量前後文時用 `context_lines`，片段足夠就不再讀取。
- 同檔多區段使用 `read_file_ranges(path, ranges, root_id)`；每區段指定 `start_line`、`line_count`，最多 16 區段，每區段 400 行及 24,000 字元，總回傳最多 512 KiB。原始順序、重疊與重複區段均保留；只開檔一次但仍驗證到 EOF。
- `read_file_ranges.truncated` 表示文字或總容量截斷；因總容量未納入的區段回傳空內容及可重試的 `next_start_line`。總容量包含保守封套預留；`next_start_line` 與單段讀取相同，不等同截斷旗標。
- 探索先用 `list_directory`，內容搜尋指定最小目錄；完整清冊用 `list_files`，完整 metadata 篩選／全域排序用 `query_files`。`query_files.limit` 只限制回傳頁，仍須完整掃描；續頁沿用條件與 `next_cursor`。

維持 4 worker、30 秒期限、1 GiB／300,000 項硬預算。文字搜尋未加入平行檔案搜尋、內容索引或驗證快取；增量基準的 metadata／雜湊快取另述於下節。更新後需在 MCP 用戶端重新整理工具契約；本機測試成功不代表遠端用戶端已接受更新。性能測試方式及本次實測見 [性能優化交付報告（歷史）](../history/性能優化交付報告.md)。


## 2026-09-29 雜湊、差異與增量診斷

新增 `hash_files`、`compare_paths`、`project_status`、`server_diagnostics`。服務版本 `2026.10.06.1`、契約 13、共 22 工具，設定版本為 8。

雜湊涵蓋一般檔案的原始位元組，保留 Hidden、link、排除名稱、共享根及容量限制。增量基準僅存在 MCP 程序記憶體，最長 24 小時，每個 workspace 最多 8 份；重啟或淘汰後須重新建立。只快取 metadata 與雜湊，文字讀取仍完整驗證。

更新服務後，用 `server_diagnostics` 核對實際註冊，再從用戶端 `tools/list` 確認工具可見；server 無法自行證明 ChatGPT 已取得工具。完整參數、界線與示例見 [增量與診斷工具說明](增量與診斷工具說明.md)。

## 原生圖片讀取（契約 13）

新增 `read_image(path, root_id?)`，以原生 MCP `ImageContent` 傳回 PNG 圖片，既有工具皆保留，目前共 22 個唯讀工具。支援靜態 PNG、JPEG、WebP、GIF、BMP、TIFF、ICO、PNM 與可用 build 的 AVIF；僅使用既有授權根，檔案須通過路徑、Hidden、link、排除名稱、狀態目錄及檔案身分檢查。詳見 [圖片讀取說明](圖片讀取說明.md)。

## 契約 13 格式擴充

保留 22 工具，在 read_document 加入 format_hint/table/expected_sha256，在 inspect_archive 加入 member_path/offset/length/expected_sha256。支援結構化資料、OpenDocument、EPUB、郵件、外掛字幕與更多圖片／媒體 metadata；來源唯讀與原有安全上限保留。詳見 [格式讀取說明](格式讀取說明.md)。

## 批次 metadata 查詢（契約 13）

新增單一 `query_files`，保留原有 21 個工具輸入契約。先完整掃描再篩選、排序與分頁；預設只查 metadata，不讀取檔案內容。`sort_by="created_time", order="asc", limit=1` 查詢整個安全範圍最早建立的檔案。Windows 使用真正 creation time。格式、能力與 SHA-256 僅 opt-in，且只處理本頁。參數、游標及資源限制見 [格式讀取說明](格式讀取說明.md#query_files-批次-metadata-查詢)。
